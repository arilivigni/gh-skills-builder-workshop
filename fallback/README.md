# Fallback artifacts

Save these files here during rehearsal so each hard stop in the [run of show](../run-of-show.md) has something real to show. They come from your own rehearsal of the three-step *Copilot app Cleared for Takeoff* exercise, not from the earlier five-step filtering scenario. Label them as rehearsal output when you use them on stage.

| File | Hard stop | What to save |
| --- | --- | --- |
| `exercise-outline.md` | 0:12 | The complete approved outline artifact from Prompt 1 and Gate 1, starting with `# <title>`, `Repository name:`, and `Learner copy:`. |
| `learner-validation.md` | 0:19 | Step 1 evidence from a disposable learner copy: the untouched starter's failing check and feedback, then the passing check after the TSDoc section was added. Include run links or screenshots. |
| `review-findings.md` | 0:30 | The report-only review from Prompt 3, with its findings, evidence, and untested risks. |
| `fix-and-rereview.md` | 0:30 | One genuine rehearsal finding: the approved fix round (Prompt 3b), its checks, and the re-review result. |
| `publish-readiness.md` | 0:38 | The readiness report from Prompt 4 and the Prompt 4b publication plan, which was shown but not authorized. |

`exercise-outline.md` is a file, not a branch. If you switch to a different rehearsal repository, update its title, `Repository name:`, and `Learner copy:` lines together.

The rehearsal repository itself carries the checkpoint branches `00-idea`, `02-bootstrapped`, `03-reviewed`, and `04-publish-ready`. Those branches hold repository states; they do not include these reports or a fresh Actions run. See the [pre-stage checklist](../demo-prestage-checklist.md) for how to create them.

Before committing a saved file, remove tokens, private repository URLs you do not want to share, and personal data.
