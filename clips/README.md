# Fallback clips

Record one short clip of each phase during rehearsal and keep it on the presenting laptop. Video files in this folder are git-ignored, so they never reach the repository.

| File | Phase | Show |
| --- | --- | --- |
| `phase-1.mp4` | I: outline | Prompt 1, the identity choice, Gate 1, and the returned outline artifact. |
| `phase-2.mp4` | II: bootstrap | The generated step files and workflows, then step 1 failing on the starter and passing after the learner's change. |
| `phase-3.mp4` | III: review | The report-only review, one approved fix round, and the re-review. |
| `phase-4.mp4` | IV: readiness | The readiness report and the Prompt 4b plan stopping at the publication boundary. |

Keep each clip to about 60–90 seconds. Before the workshop, play every clip on the actual display and audio setup, and make sure the files open without a network connection.

Without a network, use the clips and the saved Markdown in [`../fallback/`](../fallback/README.md); checkpoint branches cannot show a new Actions run offline. Say that a clip is a rehearsal recording whenever you play one.
